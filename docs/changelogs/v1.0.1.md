# Changelog for v1.0.1

## Features

- Add feature gating with `std`, `alloc`, `cli`, `svg`, `serde`, and `uncertainty`.
  The `timesync` module is available under `no_std`; all other modules require `std`.
  The CLI binary is gated behind the `cli` feature and excluded when disabled.
- Make `clap`, `crossterm`, `libc`, `rand`, and `serde_json` optional dependencies behind `cli`.
- Gate `instrumentation::svg` behind the `svg` feature.
