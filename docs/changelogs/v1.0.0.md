# Changelog for v1.0.0

## Initial Release

- Implement the TimeSync clock synchronisation algorithm in Rust.
  Rollover-safe fixed-bit-width counters (`Counter8`, `Counter16`, `Counter23`, `Counter24`, `Counter64`) via a generic `Counter<P>` abstraction.
- Add `TimeSynchroniser` with windowed-minimum one-way-delay tracking over a configurable drift window.
- Add `SyncedClock` for direct probe/sync state management, and `PeerClock` as a thread-safe `Arc<Mutex<_>>` wrapper with remote-start tracking.
- Add `Probe` and `PeerSync` packet traits, plus concrete `rkyv`-archived packet types (`StartClockPacket`, `AckStartClockPacket`, `SyncPacket`, `PingPacket`, `PongPacket`, `InputEventPacket`, `StatsBatchPacket`).
- Add non-blocking UDP handshake (`Initiator` / `Responder`) and `SyncScheduler` for periodic sync heartbeats.
- Add instrumentation layer: `Profiler`, `Span`, `EventId`, `EventTracker`, `LatencyAggregator`, and `Reporter` trait with a `ConsoleReporter`.
- Add SVG chart generation (`histogram_svg`, `scatter_plot_svg`).
- Add `sync-test` and `latency-demo` CLI programs.
- Optional `serde` support on `Snapshot`.
- Optional `uncertainty` feature for percentile confidence intervals via `statrs`.
- Minimum supported Rust version: 1.95 (Edition 2024).
